# 🌟 E-Portfolio | ธิดารัตน์ ยังมูล (Thidarat Yangmun)
**นักเรียนแผนการเรียนศิลป์ธุรกิจการค้าสมัยใหม่ (Modern Trade & Business Arts)**

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) ที่รวบรวมประวัติส่วนตัว ทักษะด้านธุรกิจและการตลาดดิจิทัล โครงงานจำลองธุรกิจ รวมถึงประสบการณ์และกิจกรรมทางวิชาการ เพื่อใช้สำหรับยื่นศึกษาต่อในระดับอุดมศึกษาและเผยแพร่ผลงานสาธารณะ

---

## ✨ จุดเด่นของเว็บไซต์ (Features)

- **🎨 Holographic Pastel Design:** ออกแบบด้วยโทนสีโฮโลแกรมพาสเทลเหลือบแสง (Iridescent & Glassmorphism) ทันสมัย สบายตา และรองรับภาษาไทยด้วยฟอนต์ **Prompt**
- **✏️ Live Edit Mode:** ระบบแก้ไขข้อมูลได้โดยตรงบนหน้าเว็บไซต์ (แก้ไขข้อความ, เปลี่ยนรูปโปรไฟล์, เพิ่ม/ลบแท็กทักษะ การ์ดผลงาน และกิจกรรม) พร้อมปุ่มส่งออกเป็นไฟล์ `index.html` ฉบับใหม่ได้ทันที
- **🔍 Portfolio Category Filter:** ระบบคัดกรองหมวดหมู่ผลงาน (ทั้งหมด, แผนธุรกิจและผู้ประกอบการ, การตลาดดิจิทัล & E-Commerce, การออกแบบแบรนด์และคอนเทนต์)
- **📱 Fully Responsive:** รองรับการแสดงผลอย่างสมบูรณ์ทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
- **🚀 Single-File Architecture:** เขียนด้วย HTML, CSS และ JavaScript ครบจบในไฟล์ `index.html` เพียงไฟล์เดียว พร้อมเผยแพร่ผ่าน GitHub Pages ได้ทันที

---

## 🗂️ โครงสร้างเนื้อหาภายในเว็บไซต์

1. **หน้าแรก (Home):** แนะนำตัวตน แผนการเรียน ป้ายกำกับจุดเด่น (*Young Entrepreneur*, *Digital Marketer*) และแถบสรุปข้อมูลทางการเรียน (ระดับชั้น, แผนการเรียน, GPAX และจำนวนโครงการ)
2. **แนะนำตัว (About & Skills):** เป้าหมายการศึกษาต่อด้านบริหารธุรกิจและการค้าปลีกสมัยใหม่ พร้อมทักษะสำคัญ เช่น:
   - Digital Marketing & SEO
   - E-Commerce & Live Commerce (TikTok Shop / Shopee)
   - Business Model Canvas & Pitching
   - Retail & Inventory Management
   - Content Creation & Canva / CapCut
3. **ผลงาน (Portfolio):** การ์ดแสดงผลงานและโครงงานธุรกิจพร้อมระบบคัดกรองหมวดหมู่ คำอธิบายรายละเอียด และลิงก์ดูตัวอย่างผลงาน
4. **กิจกรรมและประสบการณ์ (Activities):** ไทม์ไลน์รางวัลการแข่งขันเขียนแผนธุรกิจ การฝึกประสบการณ์วิชาชีพในธุรกิจค้าปลีกสมัยใหม่ (Modern Trade Internship) และกิจกรรมผู้ประกอบการรุ่นเยาว์
5. **ช่องทางการติดต่อ (Contact):** ข้อมูลติดต่อสาธารณะที่เหมาะสมสำหรับการเผยแพร่

---

## 🛠️ เทคโนโลยีที่ใช้พัฒนา (Tech Stack)

- **HTML5** (โครงสร้างหน้าเว็บและระบบ `contenteditable`)
- **CSS3** (Custom Properties, Flexbox, Grid, Holographic Gradient Animation, Glassmorphism)
- **Vanilla JavaScript** (ระบบกรองหมวดหมู่, Live Edit Mode, LocalStorage และ Export HTML)
- **Google Fonts:** [Prompt](https://fonts.google.com/specimen/Prompt)
- **Icons:** [Font Awesome 6](https://fontawesome.com/)

---

## 🚀 วิธีนำไปใช้งานและเผยแพร่บน GitHub Pages

1. ดาวน์โหลดหรือคัดลอกไฟล์ `index.html` และ `README.md` อัปโหลดขึ้น Repository บน GitHub (ตั้งค่าเป็น **Public**)
2. ไปที่เมนู **Settings** > **Pages**
3. ในหัวข้อ **Branch** ให้เลือก `main` (โฟลเดอร์ `/root`) แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้รับลิงก์เว็บไซต์สาธารณะพร้อมใช้งานทันที
